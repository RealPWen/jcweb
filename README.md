# JC Web (均成基金)

均成基金官方网站。专注于量化投资的专业资管机构。

## 技术栈
- 前端：HTML5, CSS3, Vanilla JS
- 构建工具：Vite
- 国际化：自定义多语言系统 (Translations.js)
- 动效库：Lenis (平滑滚动), Vanilla Tilt (卡片倾斜)
